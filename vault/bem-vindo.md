# Bem-vindo ao OBSIDIAN

Este e o seu sistema de **Knowledge Base** para alimentar o cerebro de uma IA.

## Como funciona

- Crie notas em **Markdown** para documentar conhecimento
- Use `[[links]]` para conectar notas entre si, como [[Conceitos de IA]]
- Use `#tags` para categorizar suas notas
- Visualize as conexoes no **Grafo de Conhecimento**
- Use o **Construtor de Contexto IA** para gerar contexto estruturado

## Recursos

- Editor Markdown com preview ao vivo
- Links bidirecionais entre notas
- Grafo interativo de conexoes
- Busca full-text
- Exportacao de contexto em XML, Markdown ou JSON

## Atalhos

| Atalho | Acao |
|--------|------|
| Ctrl+N | Nova nota |
| Ctrl+P | Buscar notas |
| Ctrl+S | Salvar |
| Ctrl+G | Abrir grafo |

Comece criando suas notas sobre os temas que a IA precisa conhecer!
