# Conceitos de IA

## Machine Learning

Machine Learning e um subcampo da #ia que permite que sistemas aprendam a partir de dados.

### Tipos de Aprendizado

1. **Supervisionado** - Aprende com dados rotulados
2. **Nao supervisionado** - Encontra padroes em dados sem rotulo
3. **Por reforco** - Aprende por tentativa e erro

## Large Language Models (LLMs)

LLMs sao modelos de linguagem treinados em grandes quantidades de texto. Exemplos:
- GPT
- Claude
- LLaMA

Eles usam a arquitetura [[Transformer]] para processar linguagem natural.

## Conceitos Chave

- **Embeddings**: Representacoes vetoriais de texto
- **Tokens**: Unidades basicas de processamento
- **Context Window**: Quantidade de texto que o modelo processa por vez
- **Fine-tuning**: Ajuste fino do modelo para tarefas especificas
